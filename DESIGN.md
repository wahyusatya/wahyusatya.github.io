# Design System: Wahyu Satya Computational Portfolio

## Overview

**Creative North Star: "The Neural Synthesizer & Computational Laboratory"**

This design system fuses the mathematical rigor of deep learning research with the precision of senior frontend engineering. Rather than relying on standard static cards or superficial decorative gradients, the interface acts as an active computational workbench.

The aesthetic utilizes an obsidian void ground (#07090e) populated by subtle coordinate grid topology and bioluminescent synaptic cyan (#06b6d4) and tensor violet (#8b5cf6) accents. Every section provides interactive telemetry, live canvas physics, runnable neural architectures, and verified credentials.

**Key Characteristics:**
- Mathematical clarity with Archivo & JetBrains Mono typography.
- 60fps canvas-driven physics (particle synaptic mesh, live loss curve convergence).
- High-contrast, WCAG AAA compliant dark mode palette with crisp luminous accents.
- Responsive layout with zero layout shifts and progressive enhancements.

## Colors

A high-density computational palette engineered for deep focus, research telemetry, and tactile feedback.

### Primary
- **Synaptic Cyan** (#06b6d4): Primary interactive accents, forward propagation pulses, key hyperlinks, and active states.
- **Electric Cyan Glow** (#22d3ee): Highlighting core headings and telemetry markers.

### Secondary
- **Tensor Violet** (#8b5cf6): Secondary neural layers, institutional leadership tokens, and mathematical symbols.
- **Soft Violet Glow** (#a78bfa): Secondary accents and ambient node lighting.

### Tertiary
- **Mathematical Emerald** (#10b981): Verified statuses, high model accuracy (>99%), and successful transmission states.
- **Amber Warning** (#f59e0b): Database tokens, pending evaluations, and terminal warning indicators.

### Neutral
- **Obsidian Dark Void** (#07090e): Root background layer.
- **Deep Slate Layer** (#0b0f17): Visualizer and card deep ground.
- **Surface Elevation** (#111723 / #182030): Card shells, controls panels, and interactive elements.
- **Primary Text** (#f8fafc): High contrast readable headings and active text.
- **Secondary Text** (#94a3b8): Clean readable body paragraphs.
- **Muted Text** (#64748b): Telemetry labels, metadata, and timestamps.

### Named Rules
**The Rarity of Glow Rule.** Saturated glowing accents (#06b6d4, #8b5cf6) carry active controls, status indicators, and focal headlines, occupying ≤12% of the viewport to maintain strong cognitive focus.

## Typography

**Display Font:** Archivo (with sans-serif fallbacks)
**Body Font:** Archivo (with sans-serif fallbacks)
**Label/Mono Font:** JetBrains Mono (with monospace fallbacks)

**Character:** Archivo brings geometric structural discipline, while JetBrains Mono anchors telemetry, mathematical formulas, and code snippets.

### Hierarchy
- **Display** (800, clamp(2.2rem, 5vw, 3.6rem), 1.15): Hero statement.
- **Headline** (800, clamp(1.8rem, 3.5vw, 2.5rem), 1.2): Section titles.
- **Title** (700, 1.25rem, 1.3): Project titles, card headers, and certification titles.
- **Body** (400, 1rem, 1.65): Narrative paragraphs, project descriptions, and bios (measure 65–75ch).
- **Label** (600, 0.75rem, 1.4, monospace): Telemetry tags, badge counters, and metadata chips.

### Named Rules
**The Zero-Gradient Text Rule.** Text emphasis is communicated through size, font weight, and solid high-contrast accents (#06b6d4, #f8fafc), never decorative gradient text masks.

## Layout

- Fluid container max width of 1200px centered on screen.
- Header fixed height at 72px with blur backdrop filter (16px).
- Generous vertical section rhythm (padding 6rem top, 3rem bottom) with more space above headings than below.
- Grid-based modular cards adjusting across breakpoints (1-col mobile, 2-col tablet/desktop, 3-col wide).

## Elevation & Depth

Surfaces utilize tonal layering and ambient glow rather than harsh block shadows. Deeper layers represent inactive backgrounds, while elevated cards sit on luminous glassmorphism with subtle 1px border illumination.

### Shadow Vocabulary
- **Subtle Elevation** (`box-shadow: 0 2px 8px rgba(0, 0, 0, 0.4)`): Base button and badge states.
- **Card Hover** (`box-shadow: 0 12px 30px rgba(0, 0, 0, 0.5), 0 0 20px rgba(6, 182, 212, 0.15)`): Interactive cards under pointer focus.
- **Modal Depth** (`box-shadow: 0 16px 36px -6px rgba(0, 0, 0, 0.75), 0 0 40px rgba(6, 182, 212, 0.2)`): Command palette and lightbox.

## Shapes

- Rounded corner hierarchy: Small (6px for badges/inputs), Medium (12px for buttons/cards), Large (18px for major panels), Extra Large (24px for visualizer sandbox).
- Subtle 1px borders using `rgba(255, 255, 255, 0.07)` default and transitioning to `rgba(6, 182, 212, 0.35)` on hover.

## Components

### Buttons
- **Shape:** Rounded medium (12px).
- **Primary:** Gradient cyan background with white text, box-shadow glow, translateY(-1px) on hover.
- **Secondary:** Surface elevated background with 1px border and text primary.
- **Ghost/Outline:** Transparent ground with border medium and cyan hover.

### Interactive Model Lab
- **Controller Panel:** Slate ground with live parameter sliders and architecture select dropdowns.
- **Visualizer Screen:** 60fps loss convergence canvas and active neural topology node graph.

### Command Palette
- **Shortcut:** Triggered via Ctrl+K / Cmd+K or Terminal HUD button.
- **Structure:** Search input, autocomplete suggestions, quick jumps to sections, document links, and direct email copy.

## Do's and Don'ts

### Do:
- **Do** maintain high contrast ratios (≥4.5:1 for body copy and ≥3:1 for display headings).
- **Do** test all animations against `prefers-reduced-motion: reduce`.
- **Do** ensure interactive canvas components resize smoothly with window width changes.
- **Do** provide fallback text and keyboard navigation for all interactive controls.

### Don't:
- **Don't** use generic stock gradient text or unmotivated neon halos.
- **Don't** add eyebrow kickers above headings; let the titles speak directly.
- **Don't** introduce external heavy frameworks that degrade page load speed.
